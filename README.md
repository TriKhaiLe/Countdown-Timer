# ChroniTask

A Pomodoro timer application for Windows with convenient features and a modern UI.

## Main Flow

- **Start**: Begin countdown, app hides from taskbar and moves to traybar.
- **Reset** (the Start button after being pressed): Pauses the timer, shows a confirmation dialog for reset (acts as pause).
- **New Day Reset & Change Background Color**: Double-click the date label with the left mouse button to reset for a new day and change the background color (from a predefined list).

## Utility Features

- **Drag-and-Drop Pomodoro Count**: The number of pomodoros just completed (below the Start button) can be dragged and dropped to other apps.
- **Completely Random Background Color**: Double-click the date label with the right mouse button to set a fully random background gradient.
- **Quick Add External Time**: Double-click the recent pomodoro count to open an input for adding extra minutes.
